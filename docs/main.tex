\section*{Pendahuluan}
\addcontentsline{toc}{section}{Pendahuluan}
Model CNN (\textit{Convolutional Neural Network}) adalah salah satu jenis jaringan saraf tiruan yang digunakan untuk pengolahan data seperti gambar atau time series. Di era sekarang ini, membuat model CNN hanya memerlukan import library seperti TensorFlow atau PyTorch dan menulis beberapa baris kode untuk membangun model CNN. Namun, pernahkah berpikir, bagaimana sebenarnya CNN bekerja?mengapa memerlukan parameter dari library ini? dari rasa penasaran tersebut, dilakukan pembuatan ulang CNN dari awal menggunakan Python dan NumPy, tanpa menggunakan library deep learning apapun. Dengan begitu, dapat memahami bagaimana CNN bekerja. 

\begin{prasyaratbox}
Dokumen ini membahas CNN sampai ke proses menghitung gradien secara manual. Supaya penjelasannya lebih mudah diikuti, ada dua materi dasar yang sebaiknya dipelajari terlebih dahulu:
\begin{itemize}
    \item \textbf{Kalkulus}: fungsi, turunan, turunan parsial, gradien, dan \textit{chain rule}. Materi ini digunakan saat menghitung seberapa besar perubahan loss terhadap setiap bobot dan bias.
    \item \textbf{Aljabar linear}: skalar, vektor, matriks, tensor, dimensi atau \textit{shape}, transpose, \textit{reshape}, dan perkalian matriks. Materi ini digunakan hampir di seluruh operasi CNN, mulai dari convolution sampai fully connected layer.
\end{itemize}
Tidak harus menguasai seluruh kalkulus dan aljabar linear. Minimal, pahami mengapa matriks dapat dikalikan dan bagaimana turunan berantai digunakan untuk menelusuri perubahan dari output kembali ke input.
\end{prasyaratbox}

\section*{STEP 2: Convolution dan ReLU}
\addcontentsline{toc}{section}{STEP 2: Convolution dan ReLU}
\subsection*{Convolution}
\addcontentsline{toc}{subsection}{Convolution}
Sebelum kita membahas lebih dalam tentang convolution, kita perlu memahami arti kernel. 
Kernel merupakan filter atau matriks kecil yang digunakan untuk mendeteksi fitur. Kernel ini akan melakukan proses konvolusi pada gambar input, dimana kernel akan menggeser posisi pada gambar input dan melakukan perkalian elemen demi elemen antara kernel dan bagian dari gambar input yang sedang diproses. 

\begin{figure} [H]
  \centering
  \includegraphics[width=0.5\textwidth]{operator.pdf}
  \caption{Ilustrasi proses konvolusi pada gambar input dengan kernel}
  \label{fig:konvolusi-operator}
\end{figure}

Dari kernel yang bisa digeser posisinya, itu ada nama nya, yaitu stride. Stride merupakan berapa langkah pergeseran kernel pada gambar input. Semakin besar stride, semakin cepat proses konvolusi. Untuk rumus ukuran output dari proses konvolusi:\\
\begin{equation}
H_{\text{out}} = \frac{(H + 2 * \text{pad} - K_{h})}{S} + 1
\end{equation}
yang dimana, $K$ adalah panjang kernel, $H$ adalah tinggi input (jumlah baris gambar/feature map).
\begin{equation}
W_{\text{out}} = \frac{(W_{\text{input}} + 2 * \text{pad} - K_{w})}{S} + 1
\end{equation}
Kemudian, kita lanjut arti konvolusi. Konvolusi merupakan proses perkalian elemen demi elemen antara kernel dan bagian dari gambar input, kemudian hasil perkalian tersebut dijumlahkan dan ditambahkan bias, sehingga menghasilkan output. Output dari proses konvolusi ini disebut feature map. Untuk ilustrasi proses konvolusi bisa dilihat pada gambar \ref{fig:konvolusi-operator}.

\subsection*{ReLU}
\addcontentsline{toc}{subsection}{ReLU}

\subsection*{Image-to-Column(im2col)}
\addcontentsline{toc}{subsection}{Image-to-Column}
Kalau konvolusi diimplementasikan dengan for-loop biasa (geser kernel piksel demi piksel), prosesnya akan sangat lambat di Python/NumPy, karena NumPy dioptimasi untuk operasi matriks berukuran besar (perkalian matriks/vektorisasi), bukan untuk loop bertingkat. Trik yang umum dipakai adalah im2col (image-to-column): setiap patch gambar yang akan dikalikan dengan kernel diubah menjadi satu baris pada matriks besar, sehingga seluruh proses konvolusi bisa dihitung sebagai satu kali perkalian matriks saja
\begin{lstlisting}[language=Python, caption=Fungsi im2col untuk mengubah patch gambar menjadi baris
matriks]
def im2col(x, kernel_size, stride=1):
    """
    Mengubah setiap patch gambar menjadi satu baris matrix.

    Input:
        x            : (N, C, H, W)
        kernel_size  : (KH, KW)
        stride       : langkah pergeseran kernel

    Output:
        cols         : (N * H_out * W_out, C * KH * KW)
    """

    N, C, H, W = x.shape

    KH, KW = kernel_size

    # Ukuran output convolution
    H_out = (H - KH) // stride + 1 # untuk menentukan ukuran kernel pada height
    W_out = (W - KW) // stride + 1 # untuk menentukan posisi  kernel pada weight

    # Tempat menyimpan semua patch
    cols = np.empty(
        (N, H_out, W_out, C, KH, KW),
        dtype=x.dtype
    )

    # Ambil setiap posisi kernel
    for i in range(KH):
        for j in range(KW):

            cols[:, :, :, :, i, j] = (
                x[
                    :,
                    :,
                    i:i + stride * H_out:stride,
                    j:j + stride * W_out:stride
                ]
                .transpose(0, 2, 3, 1)
            )

    # Ubah semua patch menjadi baris
    cols = cols.reshape(
        N * H_out * W_out,
        C * KH * KW
    )

    return cols
\end{lstlisting}

Setelah gambar diubah menjadi matriks $cols$ berukuran ($N \cdot H_{\text{out}} \cdot W_{\text{out}}, C \cdot K_{h} \cdot K_{w}, F$), dan kernel juga diratakan (reshape) menjadi matriks berukuran ($C \cdot K_{h} \cdot K_{w}, F$) dengan $F$ adalah jumlah filter, maka konvolusi cukup dihitung dengan satu kali perkalian matriks : $\text{cols} \odot W_{\text{col}}$

\subsection*{Convolution Forward}
\addcontentsline{toc}{subsection}{Conv Forward}
Dengan bantuan im2col, forward pass dari layer convolution bisa ditulis sebagai berikut: ubah input menjadi cols, kalikan dengan kernel yang sudah diratakan, tambahkan bias, lalu bentuk ulang hasilnya menjadi feature map

\begin{lstlisting}[language=Python, caption=Forward pass layer convolution]
  def conv2d_forward(x, W, b, stride=1):

    N, C, H, W_input = x.shape
    F, _, KH, KW = W.shape

    # Padding
    x_pad = x

    # Ambil semua patch
    cols = im2col(
        x_pad,
        kernel_size=(KH, KW),
        stride=stride
    )

    # Ubah kernel menjadi matrix
    W_col = W.reshape(F, -1).T

    # Matrix multiplication
    Z = cols @ W_col + b
    
    pad=0
    
    # Kembalikan ke bentuk feature map
    H_out = (H + 2 * pad - KH) // stride + 1
    W_out = (W_input + 2 *pad - KW) // stride + 1

    Z = Z.reshape(
        N,
        H_out,
        W_out,
        F
    )

    Z = Z.transpose(0, 3, 1, 2) # (N, H_out, W_out, F) transpose(0,3,1,2) ->  (N, F, H_out, W_out)

    conv_cache = (
        x_pad,
        W,
        stride,
        cols,
        x.shape
    )

    return Z, conv_cache

def maxpool_forward(x, size=2, stride=2):
    """
    x : input gambar
    
    Max pooling forward. Nilai yang diambil hanya nilai yang terbesar dari kernel
    """
    n, c, h, width = x.shape

    h_out = (h - size) // stride + 1 # karena channel yang dipakai hanya 1, berarti 1.1 = 1
    w_out = (width - size) // stride + 1

    out = np.empty((n, c, h_out, w_out), dtype=x.dtype)

    for i in range(h_out):
        for j in range(w_out):
            h_start = i * stride
            w_start = j * stride

            window = x[
                :,
                :,
                h_start:h_start + size,
                w_start:w_start + size
            ] # window ini hanya yang dimodif height dan weight + size...

            out[:, :, i, j] = window.max(axis=(2, 3)) # :, : -> 1. Input Image, 2. Input Channel
            
    # Simpan nilai yang dibutuhkan saat backward pass (posisi window
    # dipakai untuk menentukan ke mana gradient harus dialirkan kembali)
    pool_cache = (x, size, stride)

    return out, pool_cache


def flatten_forward(x):
    """
    Ubah feature map 4D menjadi 2D untuk dense layer.
    """
    return x.reshape(x.shape[0], -1), x.shape

\end{lstlisting}
Variabel $\text{conv\_cache}$ pada kode di atas menyimpan nilai-nilai yang dihasilkan saat forward pass (seperti input dan hasil im2col), yang nantinya dibutuhkan
lagi saat menghitung gradien pada tahap backpropagation (lihat STEP 8), supaya tidak perlu dihitung ulang dari nol

\section*{STEP 3: Pooling}
\addcontentsline{toc}{section}{STEP 3: Pooling}
Pooling merupakan proses untuk mengurangi dimensi dari feature map/output (panjang dan lebar), namun menjaga informasi penting dari feature map tersebut. Formula untuk ukuran output dari proses pooling adalah
\begin{equation}
    h_{\text{out}}, w_{\text{out}} = \frac{n_h-f}{s} + 1 \times n_c
\end{equation} 
yang dimana, $n_h$ adalah tinggi input, $n_w$ adalah lebar input, $f$ adalah ukuran filter, $s$ adalah panjang stride, dan $n_c$ adalah jumlah channel. Untuk contoh, jika memiliki feature map dengan ukuran $4 \times 4$, filter dengan ukuran $2 \times 2$ atau biasanya ditulis 2 dan stride $2 \times 2$,maka:
\begin{equation}
    \frac{4-2}{2} + 1 = 2
\end{equation}
output dari proses pooling adalah $2 \times 2$, dengan channel yang sama dengan input. Pooling yang digunakan pada projek ini adalah max pooling, yaitu mengambil nilai maksimum dari setiap filter. Untuk ilustrasi proses pooling bisa dilihat pada gambar berikut.

\begin{figure} [H]
  \centering
  \includegraphics[width=0.75\textwidth]{max-pool.pdf}
  \caption{Ilustrasi proses max pooling pada feature map}
  \label{fig:max-pool}
\end{figure}

Pooling biasanya disebut sebagai detektor fitur. Berikut implementasi max pooling forward yang digunakan pada proyek ini:

\begin{lstlisting}[language=python, caption=Forward pass max pooling]
def maxpool_forward(x, size=2, stride=2):
    """
    x : input gambar
    
    Max pooling forward. Nilai yang diambil hanya nilai yang terbesar dari kernel
    """
    n, c, h, width = x.shape

    h_out = (h - size) // stride + 1 # karena channel yang dipakai hanya 1, berarti 1.1 = 1
    w_out = (width - size) // stride + 1

    out = np.empty((n, c, h_out, w_out), dtype=x.dtype)

    for i in range(h_out):
        for j in range(w_out):
            h_start = i * stride
            w_start = j * stride

            window = x[
                :,
                :,
                h_start:h_start + size,
                w_start:w_start + size
            ] # window ini hanya yang dimodif height dan weight + size...

            out[:, :, i, j] = window.max(axis=(2, 3)) # :, : -> 1. Input Image, 2. Input Channel
            
    # Simpan nilai yang dibutuhkan saat backward pass (posisi window
    # dipakai untuk menentukan ke mana gradient harus dialirkan kembali)
    pool_cache = (x, size, stride)

    return out, pool_cache
\end{lstlisting}
Sama seperti conv2d forward, di sini juga disimpan pool cache yang berisi input dan posisi window, karena saat backpropagation kita perlu tahu piksel mana yang menghasilkan nilai maksimum agar gradien bisa dialirkan ke posisi yang tepat.

\section*{STEP 6: Softmax}
\addcontentsline{toc}{section}{STEP 6: Softmax}
Softmax merupakan fungsi aktivasi yang mengubah ke distribusi probabilitas. Maksudnya adalah output dari softmax akan memiliki nilai antara 0 dan 1, dan jumlah dari semua output softmax adalah 1. Rumus dari softmax adalah:
\begin{equation}
  \sigma(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}
\end{equation}
Pada projek ini, softmax digunakan pada output layer fully connected layer, karena cocok digunakan untuk klasifikasi. Softmax ini akan mengubah output model yang masih berupa nilai mentah atau \textit{logits} menjadi probabilitas, sehingga dapat digunakan untuk menentukan kelas dari input data. Perlu diingat bahwa softmax bukan loss function. Softmax menghasilkan probabilitas, sedangkan cross-entropy pada STEP 7 mengukur seberapa jauh probabilitas tersebut dari label yang benar.

\section*{STEP 7: Loss Function}
\addcontentsline{toc}{section}{STEP 7: Loss Function}
Loss function merupakan fungsi yang digunakan untuk mengukur seberapa baik model dalam memprediksi output. Pada projek ini, loss function yang digunakan adalah categorical cross-entropy, karena MNIST memiliki 10 kelas, yaitu digit 0 sampai 9. Jadi, loss yang digunakan bukan binary cross-entropy. Untuk satu batch yang berisi $N$ sampel dan $C$ kelas, rumusnya adalah:
\begin{equation}
  L = -\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{C} y_{i,c}\log(p_{i,c})
\end{equation}
yang dimana:
\begin{itemize}
  \item $N$ adalah jumlah sampel dalam satu batch,
  \item $C$ adalah jumlah kelas, pada projek ini $C=10$,
  \item $y_{i,c}$ bernilai 1 apabila sampel ke-$i$ termasuk kelas $c$, dan 0 untuk kelas lainnya,
  \item $p_{i,c}$ adalah probabilitas hasil softmax untuk sampel ke-$i$ pada kelas $c$.
\end{itemize}

Karena hanya kelas yang benar yang memiliki nilai $y_{i,c}=1$, implementasinya cukup mengambil $-\log(p)$ pada indeks label yang benar, kemudian dirata-ratakan. Sebelum menghitung eksponensial, setiap logits dikurangi nilai maksimum pada baris tersebut. Pengurangan ini tidak mengubah hasil probabilitas softmax, tetapi membuat perhitungan lebih stabil supaya nilai eksponensial tidak terlalu besar.

\begin{lstlisting}[language=Python, caption=Softmax dan categorical cross-entropy]
def softmax_cross_entropy(z, y):
    z = z - np.max(z, axis=1, keepdims=True)

    exp_z = np.exp(z)
    probs = exp_z / np.sum(exp_z, axis=1, keepdims=True)

    n = z.shape[0]
    loss = -np.log(probs[np.arange(n), y] + 1e-12).mean()

    dz = probs.copy()
    dz[np.arange(n), y] -= 1
    dz /= n

    return loss, dz
\end{lstlisting}

Ketika softmax dan categorical cross-entropy digabungkan, gradien loss terhadap logits menjadi lebih sederhana:
\begin{equation}
  \frac{\partial L}{\partial z} = \frac{p-y}{N}.
\end{equation}
Nilai gradien ini disimpan pada variabel \texttt{dz} dan menjadi titik awal proses backpropagation pada STEP 8 \cite{goodfellow2016deep}.

\section*{STEP 8: Backpropagation}
\addcontentsline{toc}{section}{STEP 8: Backpropagation}
Pada forward pass, data bergerak dari input menuju output sampai menghasilkan loss. Namun, model belum mengetahui bobot mana yang harus diperbaiki. Backpropagation digunakan untuk menghitung seberapa besar pengaruh setiap bobot dan bias terhadap loss dengan menelusuri jaringan dari output kembali ke input. Ide ini menggunakan \textit{chain rule} dari kalkulus \cite{rumelhart1986backprop}.

Sebagai contoh sederhana, apabila loss $L$ dipengaruhi oleh $z$, sedangkan $z$ dipengaruhi oleh $x$, maka:
\begin{equation}
  \frac{\partial L}{\partial x}
  = \frac{\partial L}{\partial z}
    \frac{\partial z}{\partial x}.
\end{equation}
Artinya, gradien dari layer setelahnya dikalikan dengan turunan lokal dari operasi yang sedang dilewati. Inilah alasan nilai-nilai pada forward pass disimpan ke dalam \texttt{layer\_caches}: nilai tersebut dapat digunakan kembali tanpa menghitung forward pass dari awal.

\subsection*{Backward pada Fully Connected dan ReLU}
\addcontentsline{toc}{subsection}{Backward pada Fully Connected dan ReLU}
Jika operasi pada fully connected layer ditulis sebagai $Z=AW+b$, maka gradiennya adalah:
\begin{align}
  dW &= A^{T}dZ,\\
  db &= \sum_{i=1}^{N} dZ_i,\\
  dA &= dZW^{T}.
\end{align}
Urutan transpose pada rumus tersebut penting supaya shape matriks hasilnya sama dengan shape parameter yang akan diperbarui. 

\subsection*{Backward pada Flatten dan Max Pooling}
\addcontentsline{toc}{subsection}{Backward pada Flatten dan Max Pooling}
Flatten tidak mengubah nilai, tetapi hanya mengubah shape. Oleh karena itu, backward flatten cukup mengembalikan gradien ke shape sebelum flatten. Pada max pooling, gradien hanya dikirim ke posisi yang menghasilkan nilai maksimum pada setiap window. Posisi lainnya mendapat gradien nol.

\begin{lstlisting}[language=Python, caption=Backward max pooling dan flatten]
def maxpool_backward(dout, pool_cache):
    x, size, stride = pool_cache
    n, c, h, width = x.shape
    h_out, w_out = dout.shape[2], dout.shape[3]

    dx = np.zeros_like(x)

    for i in range(h_out):
        for j in range(w_out):
            h_start = i * stride
            w_start = j * stride

            window = x[:, :, h_start:h_start + size,
                       w_start:w_start + size]
            window_max = window.max(
                axis=(2, 3), keepdims=True
            )
            mask = (window == window_max)

            dx[:, :, h_start:h_start + size,
               w_start:w_start + size] += (
                mask * dout[:, :, i, j][:, :, None, None]
            )

    return dx

def flatten_backward(dout, shape):
    return dout.reshape(shape)
\end{lstlisting}

Apabila ada dua nilai maksimum yang sama di dalam satu window, implementasi di atas akan mengalirkan gradien ke seluruh posisi yang sama-sama maksimum. Hal ini terjadi karena seluruh posisi tersebut bernilai \texttt{True} pada mask.

\subsection*{Backward pada Convolution}
\addcontentsline{toc}{subsection}{Backward pada Convolution}
Pada forward convolution, patch input sudah diubah menjadi matriks \texttt{cols}. Misalkan $dZ_{\text{col}}$ adalah gradien output convolution yang sudah diratakan, maka:
\begin{align}
  dW_{\text{col}} &= \text{cols}^{T}dZ_{\text{col}},\\
  db &= \sum dZ_{\text{col}},\\
  d\text{cols} &= dZ_{\text{col}}W_{\text{col}}^{T}.
\end{align}
Setelah mendapatkan $d\text{cols}$, setiap patch dikembalikan ke posisi asalnya pada input. Jika beberapa patch bertumpuk pada piksel yang sama, gradiennya dijumlahkan.

\begin{lstlisting}[language=Python, caption=Backward layer convolution]
def conv2d_backward(dz, conv_cache):
    x_pad, w, stride, cols, x_shape = conv_cache
    n, c, h, width = x_shape
    f, _, kh, kw = w.shape
    h_out, w_out = dz.shape[2], dz.shape[3]

    w_col = w.reshape(f, -1).T
    dz_reshaped = dz.transpose(0, 2, 3, 1).reshape(
        n * h_out * w_out, f
    )

    dw_col = cols.T @ dz_reshaped
    dw = dw_col.T.reshape(w.shape)
    db = dz_reshaped.sum(axis=0)

    dcols = dz_reshaped @ w_col.T
    dcols = dcols.reshape(n, h_out, w_out, c, kh, kw)
    dx_pad = np.zeros_like(x_pad)

    for i in range(kh):
        for j in range(kw):
            patch = dcols[:, :, :, :, i, j]
            patch = patch.transpose(0, 3, 1, 2)
            dx_pad[:, :,
                   i:i + stride * h_out:stride,
                   j:j + stride * w_out:stride] += patch

    return dx_pad, dw, db
\end{lstlisting}

Semua backward layer tersebut kemudian disusun dengan urutan yang berlawanan dari forward pass: output dense $\rightarrow$ ReLU dense $\rightarrow$ dense pertama $\rightarrow$ flatten $\rightarrow$ max pooling $\rightarrow$ ReLU convolution $\rightarrow$ convolution.

\begin{lstlisting}[language=Python, caption=Urutan backpropagation seluruh CNN]
def backward_cnn(dz3, layer_caches, params):
    W1, b1, W2, b2, W3, b3 = params

    # Output dense
    A2, W3 = layer_caches['dense3']
    dW3 = A2.T @ dz3
    db3 = dz3.sum(axis=0)
    dA2 = dz3 @ W3.T

    # ReLU dan dense pertama
    dz2 = dA2 * (layer_caches['relu2'] > 0)
    F, W2 = layer_caches['dense2']
    dW2 = F.T @ dz2
    db2 = dz2.sum(axis=0)
    dF = dz2 @ W2.T

    # Flatten, max pooling, dan ReLU convolution
    dP1 = flatten_backward(dF, layer_caches['flat'])
    dA1 = maxpool_backward(dP1, layer_caches['pool1'])
    dz1 = dA1 * (layer_caches['relu1'] > 0)

    # Convolution
    dX, dW1, db1 = conv2d_backward(
        dz1, layer_caches['conv1']
    )

    return dW1, db1, dW2, db2, dW3, db3
\end{lstlisting}
Hasil fungsi ini masih berupa gradien. Parameter model baru benar-benar berubah ketika gradien tersebut digunakan pada tahap optimasi berikutnya.

\section*{STEP 9: Gradient Descent}
\addcontentsline{toc}{section}{STEP 9: Gradient Descent}
Backpropagation dan gradient descent memiliki tugas yang berbeda. Backpropagation menghitung gradien, sedangkan gradient descent menggunakan gradien tersebut untuk memperbarui parameter supaya loss bergerak ke arah yang lebih kecil. Untuk setiap parameter $\theta$, proses update ditulis sebagai:
\begin{equation}
  \theta \leftarrow \theta - \eta\nabla_{\theta}L,
\end{equation}
yang dimana $\eta$ adalah learning rate. Tanda minus digunakan karena gradien menunjukkan arah kenaikan paling cepat, sedangkan tujuan training adalah menurunkan loss \cite{goodfellow2016deep}.

Sebelum melihat implementasinya, ada tiga hyperparameter penting:
\begin{itemize}
  \item \textbf{Epoch} adalah satu kali proses ketika seluruh data training sudah dilewati. Epoch terlalu sedikit dapat membuat model belum selesai belajar, sedangkan terlalu banyak dapat meningkatkan risiko overfitting.
  \item \textbf{Batch size} adalah jumlah sampel yang diproses sebelum parameter diperbarui. Batch kecil menghasilkan update lebih sering dan lebih berisik, sedangkan batch besar membutuhkan memori lebih banyak tetapi perhitungannya biasanya lebih stabil.
  \item \textbf{Learning rate} menentukan besar langkah update. Nilai terlalu kecil membuat training lambat, sedangkan nilai terlalu besar dapat membuat loss naik-turun atau bahkan gagal konvergen.
\end{itemize}

Pada awal setiap epoch, indeks data diacak menggunakan fungsi \texttt{permutation} dari NumPy. Setelah satu batch menyelesaikan forward pass dan backward pass, seluruh bobot dan bias diperbarui menggunakan learning rate yang sama.

\begin{lstlisting}[language=Python, caption=Training CNN menggunakan mini-batch gradient descent]
def train_cnn_with_history(
    X, y, X_val, y_val,
    epochs=1, batch_size=128, lr=0.01
):
    params = init_parameters_cnn()
    n = X.shape[0]
    history = {
        'train_loss': [], 'train_acc': [],
        'val_loss': [], 'val_acc': [],
        'batch_loss': [],
    }

    for epoch in range(1, epochs + 1):
        idx = np.random.permutation(n)
        X_sh, y_sh = X[idx], y[idx]
        losses, correct, total = [], 0, 0

        for start in range(0, n, batch_size):
            xb = X_sh[start:start + batch_size]
            yb = y_sh[start:start + batch_size]

            logits, layer_caches = forward_cnn(xb, params)
            loss, dz3 = softmax_cross_entropy(logits, yb)
            losses.append(loss)
            history['batch_loss'].append(float(loss))
            predictions = np.argmax(logits, axis=1)
            correct += np.sum(predictions == yb)
            total += yb.shape[0]

            gradients = backward_cnn(
                dz3, layer_caches, params
            )
            dW1, db1, dW2, db2, dW3, db3 = gradients
            W1, b1, W2, b2, W3, b3 = params

            W1 -= lr * dW1; b1 -= lr * db1
            W2 -= lr * dW2; b2 -= lr * db2
            W3 -= lr * dW3; b3 -= lr * db3
            params = (W1, b1, W2, b2, W3, b3)

        train_loss = np.mean(losses)
        train_acc = correct / total
        val_loss, val_acc = evaluate_cnn(
            X_val, y_val, params
        )

        history['train_loss'].append(train_loss)
        history['train_acc'].append(train_acc)
        history['val_loss'].append(val_loss)
        history['val_acc'].append(val_acc)

    return params, history
\end{lstlisting}

Eksperimen pada notebook menggunakan 5 epoch, batch size 512, dan learning rate 0.01. Nilai tersebut bukan aturan tetap. Hyperparameter dapat diubah dan dibandingkan dengan melihat apakah loss turun secara stabil serta apakah akurasi pada data yang tidak digunakan untuk update ikut membaik.

\section*{STEP 10: Evaluasi Model}
\addcontentsline{toc}{section}{STEP 10: Evaluasi Model}
Setelah parameter diperbarui, model perlu dievaluasi untuk melihat apakah prediksinya membaik. Fungsi berikut membagi data evaluasi menjadi beberapa batch supaya seluruh data tidak harus dimasukkan ke memori pada waktu yang sama.

\begin{lstlisting}[language=Python, caption=Menghitung loss dan accuracy model]
def evaluate_cnn(X, y, params, batch_size=512):
    total_loss = 0.0
    correct = 0
    total = 0

    for start in range(0, X.shape[0], batch_size):
        xb = X[start:start + batch_size]
        yb = y[start:start + batch_size]

        logits, _ = forward_cnn(xb, params)
        loss, _ = softmax_cross_entropy(logits, yb)

        bs = yb.shape[0]
        total_loss += loss * bs
        predictions = np.argmax(logits, axis=1)
        correct += np.sum(predictions == yb)
        total += bs

    return total_loss / total, correct / total
\end{lstlisting}

Loss setiap batch dikalikan kembali dengan jumlah sampel pada batch tersebut sebelum dijumlahkan. Hal ini penting karena batch terakhir belum tentu memiliki ukuran yang sama. Accuracy dihitung dengan rumus:
\begin{equation}
  \text{accuracy} = \frac{\text{jumlah prediksi benar}}
  {\text{jumlah seluruh sampel}}.
\end{equation}
Kelas prediksi diambil dari indeks logits terbesar menggunakan \texttt{argmax}. Softmax tidak perlu dihitung lagi untuk menentukan kelas, karena softmax mempertahankan urutan nilai logits.

Pola ini menunjukkan bahwa parameter yang diperbarui oleh gradient descent membuat prediksi model semakin baik pada lima epoch tersebut. Namun, hasil ini belum cukup untuk menyimpulkan bahwa konfigurasi tersebut adalah konfigurasi terbaik; eksperimen dengan epoch, batch size, dan learning rate lain tetap diperlukan.

\begin{tcolorbox}[
    colback=myred!5,
    colframe=myred,
    title=Catatan tentang data evaluasi,
    fonttitle=\bfseries
]
Di notebook, fungsi training menerima nama parameter \texttt{X\_val} dan \texttt{y\_val}, tetapi argumen yang diberikan sebenarnya adalah \texttt{X\_test} dan \texttt{y\_test}. Artinya, test set dilihat pada setiap epoch. Hasil di atas tetap ditampilkan sesuai notebook, tetapi untuk eksperimen yang lebih ketat sebaiknya data dibagi menjadi training, validation, dan test. Validation set digunakan untuk memilih hyperparameter, sedangkan test set digunakan satu kali setelah seluruh keputusan training selesai. Pembagian ini membantu menjaga evaluasi akhir tetap netral \cite{goodfellow2016deep}.
\end{tcolorbox}

Implementasi CNN dari awal ini memperlihatkan hubungan lengkap antara forward pass, loss, backpropagation, gradient descent, dan evaluasi. Pendekatan berbasis gradien yang sama juga menjadi dasar penggunaan CNN pada pengenalan digit tulisan tangan \cite{lecun1998gradient}.
